## Preamble
JITCITA is an annual IT-related event organized by [Universidad Autónoma de Asunción](https://www.linkedin.com/school/universidad-autonoma-de-asuncion) and [Universidad Católica de Asunción](https://universidadcatolica.edu.py/), consisting of a 3-day conference and a 4-day workshop. 

In the [2025 edition](https://www.linkedin.com/posts/decareaga_uaa-jitcita2025-tecnolog%C3%ADa-activity-7389282689138446336-E2Y4/?originalSubdomain=es), the workshop I choose was about a demo of video game development by making an Asteroids clone using LUA and the [LÖVE](https://www.love2d.org/) framework in VS Code.

The event took place from November 3 to November 8

Our instructor was [Mauricio Verdún](https://www.linkedin.com/in/jxpitwrr/)

## Instructions
- Install the LÖVE2D framework (I installed `love-11.5-win64.exe`)
- Install in your VS Code the "Lua" extension by sumneko
- Install in your VS Code the "Love2D Made Easy" extension by lwz7512
- Download and open this repo's folder in VS Code
- Open `main.lua` and click on the "Love2d Run" button at the top-left to run the game
